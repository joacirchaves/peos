# PEOS — Product Engineering Operating System

Bem-vindo ao **PEOS (Product Engineering Operating System)**.

Este repositório é a base de um framework de Engenharia de Produtos para Product Owners, Product Managers, Business Analysts, Arquitetos, Desenvolvedores e QA.

## Objetivo

Construir um sistema operacional de conhecimento para transformar demandas de negócio em histórias claras, testáveis e prontas para desenvolvimento.

O PEOS organiza práticas de:

- Engenharia de Requisitos
- Refinamento de Backlog
- Product Discovery
- Story Mapping
- Templates
- Prompts
- Integrações com Jira, Notion e GitHub
