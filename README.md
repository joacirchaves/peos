# PEOS — Product Engineering Operating System

Bem-vindo ao **PEOS (Product Engineering Operating System)**.

Este repositório é a base para um framework de Engenharia de Produtos voltado para Product Owners, Product Managers, Business Analysts, Arquitetos, Desenvolvedores e QA.

## Objetivo

Construir um sistema operacional de conhecimento para:

- Engenharia de Requisitos
- Refinamento de Backlog
- Product Discovery
- Story Mapping
- Templates
- Prompts
- Integrações com Jira, Notion e GitHub
